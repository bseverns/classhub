**Mission:** Join class, open a lesson, and leave with one saved artifact.

## Materials
- Class code from teacher
- Browser
- Any text editor

## Activity
1. Join with class code + display name.
2. Open this lesson.
3. Write two lines in a local text file:
    - One thing that worked
    - One thing to try next

## Rubric / checklist
- [ ] Joined the correct class
- [ ] Opened Session 1 lesson page
- [ ] Saved a local note with 2 lines

## Helper prompt example (bounded)
Use the helper like this:

> "I joined class but I am unsure what to do next. Ask me what I already tried and give one next step, not the full answer."
