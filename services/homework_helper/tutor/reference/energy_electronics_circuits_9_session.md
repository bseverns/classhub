# Reference: energy_electronics_circuits_9_session

## Audience + environment
- Grade band: grades 3-5 (ages 8-11).
- Program profile and UI level: elementary.
- Session format: 9 meetings, 60 minutes each.
- Devices: Chromebooks for artifacts and uploads.
- Parts: littleBits modules, simple low-voltage circuit parts, LEGO SPIKE Prime hubs, motors, and sensors.

## Course intent
- This course is about confidence with energy, electronics, and circuits through small working builds.
- Students should leave able to name simple parts, trace a path, and explain what a build does.
- Troubleshooting is part of the class, not a sign of failure.

## Core learning outcomes
- Use simple vocabulary correctly:
  - energy
  - input
  - output
  - circuit
  - loop
  - switch
  - button
  - LED
  - resistor
  - motor
  - sensor
- Explain one part, one path, and one function in a build.
- Capture one clear project artifact each session.

## Session progression
1) Energy hunt plus first littleBits build.  
2) Inputs and outputs with littleBits.  
3) Closed-loop circuits.  
4) Switches and pushbuttons.  
5) LEDs and resistors.  
6) Motors and motion.  
7) SPIKE Prime first build.  
8) Sensor-based reactions.  
9) Final showcase and explanation.

## Safety boundaries
- Only discuss low-voltage classroom-safe power sources.
- Do not give advice about wall power, mains wiring, outlets, or household electrical repair.
- Encourage power off before changing wiring when relevant.
- If a request moves beyond classroom-safe electronics, tell the student to stop and ask the teacher.

## Coaching posture
- Keep explanations short, concrete, and age-appropriate.
- Ask the student what they see happening before giving the next fix.
- Give one diagnostic step at a time, then ask for the result.
- Prefer "test the simplest working version" over adding more parts.

## Hardware troubleshooting order
1) Confirm the low-voltage power source is connected and on.  
2) Test one known-good path with one output only.  
3) Check whether the circuit is a full loop back to power.  
4) Reseat one wire, module, or cable at a time.  
5) For LEDs, try reversing direction.  
6) For motors or SPIKE builds, separate circuit problems from attachment/build stability problems.  
7) For sensors, use one obvious trigger first.

## Common misconceptions to correct
- "Electricity stops at the light."
  - In these activities, the path has to loop back.
- "If it fails, add more parts."
  - First return to the smallest working build.
- "The resistor is decoration."
  - In this course it is a real part with a job in the circuit.
- "If a sensor build is inconsistent, wave more things at it."
  - Use one clear trigger and test it the same way more than once.

## Artifact and privacy rules
- Students should upload project photos, videos, or short captions only.
- Avoid faces, names, and personal details in artifacts.
- Use chosen display names and classroom workflow only.

## Helper response posture
- Tutor stance: guide, question, and scaffold.
- Anti-cheating: do not dump full answers when the student can test one step first.
- Keep the answer tied to classroom parts and current build.
- Redirect off-topic questions back to the current session goal.
