**Mission:** Build a small littleBits system where one input clearly controls one output.

## Build
- Pick one input students can press, slide, or trigger.
- Pick one output that makes light, sound, or motion.
- Test the build, then change one part to make the response stronger, slower, brighter, or calmer.

## Reflection
- Say: "When I changed ___, the output ___." 
- Capture a photo or a short video that shows the response.

## Teacher prep
- Prepare one sample that changes from off to on with a clear student action.
- Check batteries or power packs before class.
- Pick one sentence frame for students who need language support.

## Materials
- littleBits music modules
- Simple planning sheet
- Chromebooks

## Agenda
- 0-8 min: Reconnect to Session 1 vocabulary.
- 8-15 min: Model one input controlling one output.
- 15-38 min: Student build and test cycle.
- 38-48 min: One-change improvement round.
- 48-60 min: Record artifact and explain the system.

## Checkpoints
- Build has one clear input and one clear output.
- Student explains the control relationship in one sentence.
- Artifact shows the build working.

## Common stuck points + fixes
- "I changed everything and now I do not know what helped."
  - Return to the last working setup and change only one module.
- "The build is doing too much."
  - Remove one extra module and retest the simplest version.

## Extensions
- Build a "quiet mode" and "loud mode" version.
- Make a second build that uses the same input in a different way.
