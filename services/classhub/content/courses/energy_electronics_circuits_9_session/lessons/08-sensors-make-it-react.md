**Mission:** Build something that reacts when a sensor notices a change.

## Build
- Pick one sensor input and one output.
- Test the system with one clear trigger.
- Repeat the test until the reaction works on purpose.

## Reflection
- Finish the sentence: "When the sensor notices ___, the build ___."
- Record a short clip that shows the trigger and the response.

## Teacher prep
- Test one sensor example before class with an obvious trigger.
- Arrange room space so students can test without bumping each other.
- Keep one backup kit ready for cable or battery swaps.

## Materials
- SPIKE Prime sensors
- hubs
- motors or lights
- Chromebooks

## Agenda
- 0-10 min: Review input and output with sensor examples.
- 10-18 min: Model one obvious trigger.
- 18-42 min: Student build and test cycle.
- 42-52 min: Repeatable demonstration round.
- 52-60 min: Record artifact and explain cause and effect.

## Checkpoints
- Sensor trigger is identified.
- Output reaction is visible.
- Student can explain the system in one sentence.

## Common stuck points + fixes
- "I do not know if the sensor sees anything."
  - Use one large obvious trigger first, then refine.
- "The build reacts sometimes but not every time."
  - Reduce extra changes and test the same trigger three times.

## Extensions
- Add one more response, such as light plus motion.
- Design a classroom display card that invites another student to test the build.
