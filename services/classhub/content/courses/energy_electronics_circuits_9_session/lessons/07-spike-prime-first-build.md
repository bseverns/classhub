**Mission:** Build your first SPIKE Prime model and make one connected part respond in a clear way.

## Build
- Identify the hub and one part you want to use first.
- Build a simple stable base before adding extras.
- Test one motor or sensor response, then capture the result.

## Reflection
- Say: "The hub tells the ___ to ___."
- Take a photo or short clip of the working model.

## Teacher prep
- Build and test one small SPIKE Prime sample before class.
- Charge hubs and check that cables are sorted.
- Keep expectations on one clear success, not a large finished robot.

## Materials
- LEGO SPIKE Prime hubs
- SPIKE motors
- SPIKE sensors
- Chromebooks or tablets if used with the kit

## Agenda
- 0-10 min: Identify hub, cable, motor, and sensor.
- 10-20 min: Build the base model.
- 20-42 min: Connect and test one active part.
- 42-52 min: Stabilize and improve the model.
- 52-60 min: Record artifact and explain parts.

## Checkpoints
- Hub powers on.
- One connected part responds.
- Student names the main parts used.

## Common stuck points + fixes
- "The model is falling apart."
  - Fix the base before adding more parts or code changes.
- "The part is plugged in but not responding."
  - Reconnect one cable and test only that part.

## Extensions
- Add one second controlled action if time allows.
- Create a simple comparison chart between loose circuits and SPIKE Prime parts.
