    Documentation Index¶

    Summary¶

    This page is the complete reference index for the docs stack. For role routing, start with START_HERE.md. For conflicts between overlapping docs, use CANONICAL_TRUTHS.md.

    What to do now¶

    1. Use START_HERE.md if you need a reader journey.
    2. Use the sections below when you already know the topic.
    3. Use CANONICAL_TRUTHS.md before changing any policy-sensitive claim.

    Verification signal¶

    You should be able to find the canonical doc for a topic without opening multiple role pages.

    3. Add one verification signal.
    4. Link major new reader paths from START_HERE.md.
