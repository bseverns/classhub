# Teacher Docs Journey

## Summary
This is the recommended wiki read path for teachers and assistants.
It is designed for non-developers: short, practical, and ordered by "what you need right now."

## What to do now
1. Start with the 10-minute path below.
2. Use the full read order when you have 30-45 minutes.
3. Keep this page bookmarked as your "where do I read next?" index.

## Verification signal
A first-time teacher should be able to answer "What do I do before class, during class, and after class?" in under 15 minutes of reading.

## If you only have 10 minutes
1. [START_HERE_INSTRUCTOR.md](START_HERE_INSTRUCTOR.md): what ClassHub is, what success looks like.
2. [RUN_A_CLASS_TOMORROW.md](RUN_A_CLASS_TOMORROW.md): exact steps for a live class day.
3. [COMMON_SCENARIOS.md](COMMON_SCENARIOS.md): what to do when something breaks.
4. [LESSON_OVERRIDES.md](LESSON_OVERRIDES.md): how to make a reversible class-specific lesson change without editing shared curriculum files.

## Mental model that helps this stick

- `Before class`: use [RUN_A_CLASS_TOMORROW.md](RUN_A_CLASS_TOMORROW.md).
- `During class`: use [NON_DEVELOPER_GUIDE.md](NON_DEVELOPER_GUIDE.md) + [COMMON_SCENARIOS.md](COMMON_SCENARIOS.md).
- `After class`: use [TEACHER_PORTAL.md](TEACHER_PORTAL.md) for closeout and exports.
- `If there is an outage or blocker`: use [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## Suggested onboarding script (for leads)

Read this to a new teacher in 60 seconds:

> "You do not need to learn the whole system at once. Start with `START_HERE_INSTRUCTOR`, run tomorrow with `RUN_A_CLASS_TOMORROW`, and keep `COMMON_SCENARIOS` open during class. If you need exact button-level details, use `TEACHER_PORTAL`. If something truly breaks, move to `TROUBLESHOOTING`."
