    Stability Owner + Cadence Tracker¶

    This document is the governance tracker for the five maintenance risks in the stability register.

    Last updated: March 10, 2026

    Purpose¶

    Use this file to make ownership and review cadence explicit: - who owns each risk - who is backup owner - when the next review is due - where evidence is stored

    Risk Ownership Matrix¶

    Risk ID Risk title Primary owner role Backup owner role Cadence Next review date Evidence location
    R1 Teacher portal surface area Maintainer + Ops Director Teacher Lead Monthly 2026-04-10 artifacts/stability/<date>/operator_scorecard.md + teacher walkthrough notes
    R2 Org boundary fallback drift Ops Director Executive Director Monthly 2026-04-10 ORG_BOUNDARY_POLICY_AUDIT.md
    R3 Outcomes/certificate semantic drift Ops Director Executive Director Monthly 2026-04-10 OUTCOME_SEMANTICS.md review notes + REPORTING_REHEARSAL.md evidence row
    R4 Retention/recovery ritual drift Ops Director + Maintainer Engineering manager Monthly retention, quarterly restore 2026-04-10 (monthly), 2026-06-10 (quarterly) artifacts/stability/<date>/restore_rehearsal.log + restore_rehearsal_metrics.json + retention_health.log + RESTORE_REHEARSAL_LOG.md
    R5 Turnover survivability dependence Executive Director + Ops Director + Maintainer Secondary maintainer Quarterly 2026-06-10 TURNOVER_PACKET.md + TURNOVER_DRILL_LOG.md

    Review Run Template¶

    Use one row per review cycle.

    Date Risk IDs reviewed Reviewer(s) Result Follow-up actions Due date Evidence path
    2026-03-10 R1,R2,R3,R4,R5 ben (maintainer) concerns Complete turnover drill row, capture telemetry Slice 7 packet with rollback drill, and finalize Gate C decision note (dual retained / Gate D deferred). 2026-03-17 artifacts/stability/2026-03-10/operator_scorecard.md + TEACHER_TOP_TASKS.md + ORG_BOUNDARY_POLICY_AUDIT.md
    2026-03-10 R1,R2,R3,R4,R5 ben (maintainer) concerns Stability closeout and telemetry Slice 7 evidence passed (parity, strict smoke, rollback drill). Remaining open item: run and record an independent turnover drill for R5 before final sign-off. 2026-03-17 artifacts/stability/2026-03-10/cycle_closeout_summary.md + artifacts/stability/2026-03-10/telemetry/summary.md + TURNOVER_DRILL_LOG.md
    YYYY-MM-DD R1,R2 names/roles pass / concerns short list YYYY-MM-DD artifacts/stability/...

    Completion Rule For Issue 1¶

    Issue 1 is complete when: - every risk in MAINTENANCE_RISK_REGISTER.md has: - primary owner role - backup owner role - cadence - next review date - this tracker is referenced from active stability docs
